# Gap Analysis: IR-2026-0414-01

## Gap Register

| Gap ID | Phase | Gap Description | Control Category | Recommended Improvement | Priority | Linked Findings |
|---|---|---|---|---|---|---|
| GAP-001 | Credential phishing and submission | Lack of FIDO2-based phish-resistant MFA on external webmail and single sign-on (SSO) portals enabled session/credential capture via reverse proxy phishing kit. | Preventive | Enforce mandatory FIDO2/WebAuthn hardware security key authentication (or certificate-based authentication) across all enterprise SSO applications and remote access portals, deprecating SMS/push notifications. | P1 | control_eff phase 1, ART-001-F01 |
| GAP-002 | VPN access using stolen credentials from a foreign IP | MedDefense perimeter VPN lacks Geo-IP velocity validation and automated threat intelligence feed enrichment, allowing authentication from foreign IP addresses without secondary verification. | Preventive / Detective | Configure Azure AD / Okta Conditional Access policies with Location-Based Access Controls and Risk-Based Sign-in Policies to automatically require step-up authentication or block logins from non-compliant foreign IPs. | P1 | control_eff phase 2, ART-001-F02 |
| GAP-003 | PowerShell to MSBuild LOLBin execution | EDR policy failed to block execution of trusted developer utilities (`MSBuild.exe`) spawned directly from interactive shell sessions (`PowerShell.exe`) executing inline untrusted XML code. | Preventive | Deploy Microsoft Attack Surface Reduction (ASR) rule `3B576869-A43B-4FD2-A31E-1469D5072B28` ("Block executable files from running unless they meet a prevalence, age, or trusted list criterion") and configure AppLocker/WDAC policy to constrain `MSBuild.exe` execution to authorized developer workstations. | P1 | control_eff phase 3, ART-001-F03 |
| GAP-004 | PowerShell to MSBuild LOLBin execution | Lack of tuned real-time SIEM alert rules mapping process spawning relationships for built-in administrative and developer binaries. | Detective | Deploy Sigma detection rule matching Sysmon Event ID 1 where `ParentImage` ends in `powershell.exe` or `cmd.exe` and `Image` ends in `msbuild.exe` or `csc.exe`, configured for high-severity SIEM alerting. | P2 | control_eff phase 3, ART-001-F03 |
| GAP-005 | C2 beaconing to external IPs | Egress firewall and web proxy rules allowed outbound direct TCP communication on non-standard ports to known malicious external infrastructure. | Preventive | Implement restrictive outbound egress filtering on firewalls, enforcing mandatory HTTP/HTTPS proxy inspection and blocking outbound connections to unmapped direct external IPs. | P2 | control_eff phase 4, ART-001-F04 |
| GAP-006 | C2 beaconing to external IPs | Lack of automated threat intelligence feed ingestion (OTX/AbuseIPDB) into host and network perimeter security devices. | Detective | Integrate automated open-source and commercial C2 IP/domain threat intelligence feeds directly into firewall blocklists and SIEM correlation rules for real-time traffic matching. | P2 | control_eff phase 4, ART-001-F04 |
| GAP-007 | LSASS credential access and Kerberos ticket extraction | Host baseline configuration lacked Virtualization-Based Security (VBS) and Windows Defender Credential Guard, permitting direct memory reading of `lsass.exe`. | Preventive | Enable Windows Defender Credential Guard via Group Policy across all domain workstations and servers to isolate LSASS in a virtualized container and prevent memory dumping. | P1 | control_eff phase 5, ART-001-F05 |
| GAP-008 | LSASS credential access and Kerberos ticket extraction | Sysmon Event ID 10 (Process Access) telemetry was collected on endpoints but not monitored for suspicious process handle opening requests against `lsass.exe` with mask `0x1010` or `0x1F0FFF`. | Detective | Write and activate a high-priority SIEM detection rule for Sysmon Event ID 10 where `TargetImage` is `*\lsass.exe` and `GrantedAccess` includes write/read rights originating from non-system binaries. | P2 | control_eff phase 5, ART-001-F05 |
| GAP-009 | Lateral movement and PHI access | Absence of network micro-segmentation permitted flat routing and lateral Kerberos ticket exploitation (`Pass-the-Ticket`) between standard workstations and sensitive MedDefense PHI database subnets. | Preventive | Implement internal firewalls and VLAN micro-segmentation restricting network connectivity to PHI database clusters strictly to privileged administrative jump boxes using Tiered Administration model. | P1 | control_eff phase 6, ART-001-F06 |
| GAP-010 | Lateral movement and PHI access | Lack of anomalous database access telemetry monitoring allowed undetected bulk querying and data extraction from PHI repositories. | Detective | Deploy Database Activity Monitoring (DAM) with baseline profiling to generate automated high-priority alerts on unexpected bulk querying, off-hours access, or unmapped service account activity. | P2 | control_eff phase 6, ART-001-F06 |

## Priority summary

- **GAP-001** (P1): Unrestricted credential capture at the phishing stage enabled initial access; implementing phish-resistant FIDO2 MFA eliminates the risk of stolen session tokens and password compromise.
- **GAP-002** (P1): Foreign-IP VPN authentication was the entry point into the internal network; deploying automated location and risk-based conditional access controls stops unauthorized remote access at the perimeter.
- **GAP-003** (P1): MSBuild execution allowed inline C# code compilation and bypass of traditional antivirus; restricting LOLBin binaries via application control (WDAC/AppLocker) prevents unapproved script execution.
- **GAP-007** (P1): Unprotected LSASS memory allowed credential extraction and ticket harvesting; enabling Credential Guard isolates credential stores and neutralizes Pass-the-Ticket attacks.
- **GAP-009** (P1): Unsegmented network paths allowed lateral movement directly to sensitive healthcare data; enforcing zero-trust micro-segmentation prevents unauthorized access to PHI environments.
