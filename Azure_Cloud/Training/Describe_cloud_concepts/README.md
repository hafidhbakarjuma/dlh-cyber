# Cloud Computing Learning Path – Module Overview

This learning path is designed to build foundational knowledge of cloud computing. It consists of three modules, all of which have been completed with passing assessment scores. Below is an explanation of each module.

---

## Module 1: Describe Cloud Computing

**Duration:** 24 minutes | **Format:** Module | **Units:** 8

This introductory module lays the groundwork for understanding cloud computing. It covers core cloud concepts such as what cloud computing is, the various deployment models (public, private, and hybrid), and the shared responsibility model—explaining how security and management responsibilities are divided between the cloud provider and the customer. This module is essential for anyone new to cloud technology, as it establishes the vocabulary and principles used throughout the rest of the learning path.

---

## Module 2: Describe the Benefits of Using Cloud Services

**Duration:** 19 minutes | **Format:** Module | **Units:** 8

This module explores the practical advantages that cloud computing offers to individuals and organizations. It explains why businesses choose to move to the cloud, covering benefits such as scalability, cost efficiency, reliability, high availability, and agility. By the end of this module, learners understand the value proposition of cloud services and how they can positively impact an organization's operations and growth.

---

## Module 3: Describe Cloud Service Types

**Duration:** 13 minutes | **Format:** Module | **Units:** 6

This module focuses on the different categories of cloud services—commonly known as IaaS (Infrastructure as a Service), PaaS (Platform as a Service), and SaaS (Software as a Service). It explains what each service type provides, along with their respective use cases and benefits. This module helps learners determine which service model is appropriate for different scenarios and workloads.
