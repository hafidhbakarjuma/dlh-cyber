After learning the fundamentals in NSE 1 and the next-generation firewall in NSE 2, **NSE 3 widens the view from one firewall to the whole security ecosystem.** It shows how Fortinet products work together to protect networks, endpoints, email, web applications and cloud workloads, instead of working as separate tools.
